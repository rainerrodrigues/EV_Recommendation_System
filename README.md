🔗 API Usage
Endpoint
POST /predict

Sample Request
{
  "manufacturer": "Tesla",
  "model": "Model 3",
  "type": "Sedan",
  "drive_type": "RWD",
  "fuel_type": "Electric",
  "color": "White",
  "fast_charging": "Yes",
  "country": "USA",
  "city": "San Francisco",
  "battery_kwh": 60,
  "range_km": 450,
  "charging_time_hr": 1.2,
  "release_year": 2023,
  "seats": 5,
  "acceleration_0_100_kmph": 5.8,
  "top_speed_kmph": 225,
  "warranty_years": 8,
  "cargo_space_liters": 425,
  "safety_rating": 5
}

Response
{
  "prediction": 1
}


1 → High Efficiency

0 → Low Efficiency

🐳 Dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["uvicorn", "api.api:app", "--host", "0.0.0.0", "--port", "8000"]
